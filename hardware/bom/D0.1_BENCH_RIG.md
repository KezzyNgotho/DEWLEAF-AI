# D0.1 — Dual-Rail Electronics & Bench Rig

## Objective

Build a 1 m × 1 m, 20° sloped hydrophilic mesh canopy bench rig with dual-rail power, isolated actuator switching, calibrated sensors, and mass-verified water collection.

## Physical Build

| Item | Spec | Purpose |
|---|---|---|
| Canopy | 1 m × 1 m UV hydrophilic shade mesh, 20° slope | Passive radiative condensation and runoff |
| Nucleation spine | Anodized aluminum spine along canopy ridge | Thermal conduction for dew-point nucleation assist |
| Gutter | Sealed food-safe gutter to collection vessel | Capture shed droplets before sunrise re-evaporation |
| Collection vessel | Graduated vessel on digital scale | Ground-truth harvested mL |
| Enclosure | IP65 control vault | Field electronics protection |

## Electrical Architecture

### 12V High-Current Rail
- Source: 50W solar + MPPT + 12V 20Ah LiFePO4 (Phase 0).
- Fused branch feeds: TEC1-12706 Peltier + heatsink fan, 2x 12V vibration motors, 2x 12V solenoid/gravity valves.
- **Never route actuator current through LM2596 logic buck.**

### 5V/3.3V Logic Rail
- LM2596 buck from battery to regulated logic rail.
- Decoupling: 100 μF electrolytic + 0.1 μF ceramic near ESP32 and sensor power nodes.
- Common ground: star ground at power distribution; logic ground reference kept clean.

## Actuator Driver Stage

- 6x logic-level N-channel MOSFETs: AOD4184 or IRL540N.
- Gate: 100 Ω series resistor; 100 kΩ pull-down to ground.
- Flyback: 1N4007 reverse-parallel across every inductive load (motors, solenoids, fan if brushed).
- Peltier: MOSFET low-side switch; heatsink fan interlocked—never power Peltier without fan.

## Sensors

| Sensor | Interface | Pin/Constraint | Notes |
|---|---|---|---|
| BME280 | I2C | SDA/SCL | Air temp, RH, pressure |
| DS18B20 #1 | 1-Wire GPIO 4 | 4.7 kΩ pull-up | Nucleation spine temp; frost guard > +1.5°C |
| DS18B20 #2 | 1-Wire GPIO 4 | Shared bus | Root-zone/soil temp |
| Soil probe A | ADC1 GPIO 1 | ADC1 only | Epoxy-sealed capacitive |
| Soil probe B | ADC1 GPIO 2 | ADC1 only | Epoxy-sealed capacitive |
| YF-S201 | Pulse GPIO 5 | 7.5 Hz/L/min nominal | Behind 100-mesh inline sediment filter |
| INA219 | I2C | High-side | Measures actuator/system Wh |
| DS3231 RTC | I2C | Battery-backed | Pre-dawn scheduling |
| MicroSD | SPI | Dedicated CS | Local failover logging |

## Acceptance Checklist

- [ ] Full-load test: Peltier+fan+2 motors+2 valves energized in planned combinations; no ESP32 reset/brownout.
- [ ] BME280 readings stable and plausible vs reference meter.
- [ ] DS18B20 probes read within ±0.5°C of reference.
- [ ] Soil probes calibrated dry/wet and read on ADC1 only.
- [ ] INA219 current/voltage within ±3% against calibrated multimeter.
- [ ] YF-S201 pulses calibrated against measured volume; within ±3%.
- [ ] Flyback diodes orientation verified before first inductive load test.
- [ ] Peltier fan interlock verified.
- [ ] SD logging continues when USB serial disconnected.
